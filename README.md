# IT企業 比較ナビ（新卒エンジニア向け）

Web系・SIerのIT企業を「年収・働きやすさ・柔軟な働き方・将来性」で比べる、個人用の比較サイトです。
GitHub Pages で無料公開でき、見る人はログイン不要です。

## できること
- 重視項目のスライダーで、自分向けランキング（100点満点）を表示
- 平均年収のグラフ
- 最大4社を選んで項目ごとに比較（数値ごとに「公式／二次／要確認」と出典リンク付き）
- 企業ごとの自分用メモと選考状況（ブラウザ内だけに保存。他の人には見えない）

## ファイル構成
| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体 |
| `style.css` | 見た目 |
| `app.js` | ランキング計算・グラフ・比較表・メモ |
| `data/companies.js` | **企業データ（追加・修正はここだけ）** |

## 企業を追加・更新する方法（Claude Code に頼む）
このリポジトリを開いた Claude Code に、次のように依頼してください。

```
data/companies.js に「〇〇株式会社」を追加して。
最新の有価証券報告書・公式採用サイト・決算資料をネットで調べて、
既存の企業と同じ項目を埋めて。見つからない数値は推測せず「要確認」にして、
出典URLと conf（official / secondary / unknown）を必ず付けて。
終わったら画面で表示確認してから push して。
```

データの更新（年1回、6〜7月に有価証券報告書が出たあとがおすすめ）も同じように頼めます。

## 点数の計算方法
- 年収：平均年収から自動計算（800万円=1点〜1,450万円=5点）
- 働きやすさ・柔軟な働き方・将来性：集めた事実をもとにした1〜5点の目安。根拠は `reasons` に記載
- 合計点 =（各項目の点数 × 重み）の平均を100点満点に換算

## 注意
- 数値はAIがネット検索で集めたものです。必ず出典で原本を確認してください。
- 非公式サイトであり、掲載企業とは関係ありません。
